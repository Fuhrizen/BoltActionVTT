# BoltActionVTT

An unofficial Bolt Action Second Edition system for Foundry VTT V14. Assign players to a Player Team, choose its faction, and organise individual models into squads. Teams and squads are expandable actor groups in the sidebar with their own sheets and inherited ownership.

The GM prepares model compendiums without creating sample armies. Drag a compendium model into a squad's drop area to import an independent copy. Infantry squads hold infantry models; vehicle/static squads hold vehicles and static weapons. Individual sheets offer source profile experience, weapon and equipment choices using Foundry's default theme. Point tracking is disabled; army-list legality is not enforced. Scene management and turn sequencing are outside this iteration.

Not affiliated with Warlord Games, Osprey Publishing or Foundry Gaming. Requires the original rules; no rulebook text or artwork is distributed. Live V14 validation remains pending.
