# BoltActionVTT

An unofficial Bolt Action Second Edition system for Foundry VTT V14. Use Foundry’s Configure Ownership for an Army, choose its faction, and organise individual models into squads. Armies and squads are expandable actor groups in the sidebar with their own sheets and inherited ownership.

The Army sheet opens a separate faction-filtered builder: add source profiles and configure squads, individual roles and equipment inline without opening a compendium. Existing reference compendiums remain available. Drag a compendium model into a squad's drop area to import an independent copy. Infantry squads hold infantry models; vehicle/static squads hold vehicles and static weapons. Squads manage experience; squad sheets manage individual identities, roles, source profile weapons, equipment and vehicle states using Foundry's default theme. Source-based points aggregate from models through squads to armies; unresolved prices are identified. Source-backed army checks cover generic reinforced platoons, faction composition, quality, option counts, loaders and budget; unverified conversions remain marked for review. Drag squads or armies onto a scene to deploy their individual models. Hovering over a model lightly highlights its visible squadmates. Casualties have skull markers; default model names follow weapon/role or vehicle type until customised. Squads track orders, activation, movement, attacks and GM-controlled battle rounds.

Not affiliated with Warlord Games, Osprey Publishing or Foundry Gaming. Requires the original rules; no rulebook text or artwork is distributed. Live V14 validation remains pending.

The default squad Roll dice button opens a compact manual D6 roller: enter dice, an optional threshold and a modifier. It does not check targets, LOS, orders or apply effects. `game.boltaction.confirmManualRoll(actor)` opens it and `genericRoll(actor, input)` rolls directly. Assisted shooting remains an optional API: it requires deployed tokens and center-to-center wall LOS to a chosen scene target, then opens a confirmation card before rolling; loader availability and situational modifiers remain player-confirmed. GM preparation adds a Macro tools compendium. Macros can use `game.boltaction.confirmShooting(actor)`, `shootingPlan(actor)`, and `calculateCost(actor)` (API version 1).

Direct shooting requires an explicitly targeted scene model (friendly targets are permitted). Infantry damage and direct vehicle armour/damage tables are assisted, with target-owner allocation. Special weapons and close quarters still require manual adjudication; this alpha is not a complete rules implementation.
