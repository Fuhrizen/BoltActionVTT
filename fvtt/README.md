# Bolt Action 2e for Foundry VTT

Unofficial Second Edition system for Foundry V14. Requires the original Bolt Action rules; not affiliated with Warlord Games, Osprey Publishing or Foundry Gaming.

Build an army in the separate web builder, export its JSON, then use **Import army JSON** on an Army sheet as GM. Import creates a new owned Army with independent squad and model actors. Existing armies remain unchanged. Foundry handles native ownership, roster inspection, identities, casualty tracking, pins, vehicle states and manual dice rolling. Army construction belongs to the web builder.

This is an alpha; specialist rules can require manual adjudication. Custom artwork is preserved.
